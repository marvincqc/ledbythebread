# Look & Feel / Design System

## Brand Identity
Warm, inviting, artisanal bakery feel. Earthy tones combined with appetizing food photography.

## Colors
- **Primary:** Warm brown `#8B5E3C` (buttons, active states)
- **Accent:** Golden yellow `#F4A261` (highlights, badges)
- **Background:** Cream `#FFF8F0`
- **Text:** Dark brown `#3E2723`
- **Success:** `#4CAF50`
- **Error:** `#D32F2F`

## Typography
- **Headings:** 'Playfair Display', serif
- **Body:** 'Inter', sans-serif
- Weights: 400 (regular), 600 (semibold), 700 (bold)

## Components
- **Buttons:** Rounded (8px), hover shadow, disabled state with 50% opacity.
- **Cards:** Light shadow, border-radius 12px, white background.
- **Forms:** Clear labels, input borders #DDD, focus glow primary.
- **Delivery Slot Selector:** Calendar-like date picker with highlighted available slots; past/closed dates are greyed out with a lock icon.
- **Cart:** Floating button on mobile, slide‑in panel.

## Images
- Hero section: steaming pandesal on wooden board.
- Product thumbnails: uniform size, subtle zoom on hover.

## Mobile First
All layouts start at 375px width. Menu collapses to hamburger. Checkout is a single page scroll. Admin uses a responsive sidebar.

## Accessibility
- All interactive elements have focus states.
- Color contrast meets WCAG AA.
- Form labels always visible.
